## 先看有针对性的真实参考

首先阅读 [本轮外部资料与具体接触关系](../research/P2E-real-armwrestling-grip-reference.md)，包含 CAWF 规则、AWE 规则、裁判定握视频、真实手部近景以及 UltimateXR 编辑方法。

将这几条作为**正常右手对右手**零位姿态的参考，不做强制比赛裁判系统：

- **掌心对掌心**、双腕相对顺直、握持发生在掌部而不是抓对方腕；
- 先确定**各自**的拇指和虎口谁位于哪一侧、搭扣关系清晰且拇指关节可辨认；
- 再让食指、中指、无名指、小指沿自然屈伸方向绕到**对方掌背**，指腹贴合合理区域而非十指互钩；
- Ready 已经轻握，Contest 略收紧，不能在比赛真正开始时才突然由五指张开变成握手。

**先用真实零位近景制定可理解的接触对应说明：** 如“玩家四指指腹→对手掌背，玩家拇指→对手虎口附近；对手反之”，区分每手哪些区域**允许接触**、哪些**绝不允许互穿**。注意不同合法握法存在差异；先选一种画面自然的无绑带握姿。

## 实施：真实骨骼定姿，不是继续训练参数

1. 检查现有 Unity 2022.3.62f3c1 的 `P2-E Open Authored Grip Preview`、`AuthoredPairedGrip.asset` 和实际 RTX/CPU Editor 录屏工具；保护原 `.meta` / GUID 与本机私有 Ch03。
2. 把两个 Rocketbox 右手**同时**放在实际编辑预览中，先调**相对手腕/掌面/虎口**再逐指以真实网格调整 MCP/PIP/DIP。尽可能通过 Unity 现有 Scene View 的关节旋转操作、逐帧截图视觉复核获得实质效果；若原工具不方便，可最小扩展操作/参考线/锁定已完成关节。**不要**创建另一个角度表或无限 muscle 网格搜索，伪装成“人工摆姿态”。
3. 明确保存双方 Ready（轻握）/Contest（完整扣握）骨骼快照、两腕相对 Grip Anchor 位姿以及来源参考；重新打开 Editor 再 Load 验证。美术定义尽量保留对方掌背的接触意图，而不依赖单个模型固定骨旋转。
4. 从 0° 优先解决**掌根/虎口/拇指**的接触，再核对**四指实际皮肤位置**和双腕是否自然。零位未达到明显改善前，不进入几十轮扫角调参。可以比较 1～2 个有实质差异的手型摆法并选一套，避免在同质角度上循环。
5. 有合理零位后**立即在同一轮**接入 `ArmWrestlingMain` 的已存在 `Use Authored Grip`，正常机械角度仍决定唯一 Grip Anchor；现有 Animator、Blend Tree、IK、ContactGrip 负责运动和微小残余接触，不能破坏美术姿态。需测试 `−30/0/+30°`、一次约 181 帧往返；观察 Ready→Contest 过渡是否与已握紧的机械体验矛盾。
6. 在本机 Ch03 和 Rocketbox/Ch03 混合人物上实际使用同一套握姿工作流，通过现有 Humanoid 转换并允许 `GripAvatarProfile` 的适当**角色专属人工校准**；不可把 Rocketbox 原始 15 指 localRotation 生搬硬套到 Ch03，更不可公开 Ch03 文件、画面或私有来源。
7. 真实 Editor Play 回归至少覆盖新美术模式、P2-D 稳定默认、胶囊和缺资产回退，条件允许复查 Ch03/混合。确认动画实际播放、手掌共同跟随机械角、没有持续跳帧/腕部明显退步、胸臂和肘垫不恶化。未实测 PICO/PCVR/STM32/UDP 的一律写未测。
