# P2-E｜美术制作自然双人握姿并直接集成主场景

**状态：待 Codex 执行；继续 `feat/p2d-cross-avatar-grip` / [Draft PR #11](https://github.com/Ihtbfas/armwrestling-vr/pull/11)。不创建叠加新 PR。** 当前可靠基线是提交 `1014b7d` 的通用 Humanoid 握姿回退，P2-D 已停止盲目搜索自动关节权重。本任务转向**真正制作两只手互相握住的姿态资产**，必要时自主使用成熟编辑工具；成功后同轮修改正式场景、测试并推送。

## 验收目标

1. **零位实际画面先过关：** 两只右手按自然扳手腕方式对掌，拇指/虎口关系清晰，四指围绕对方手掌/手背形成稳定包握；不抓腕、不十指穿插、不呈张爪。正、斜侧、反侧和玩家第一人称可直接看懂握手动作。不能只靠降低代理重叠数值。
2. **完成可编辑的握姿资产：** 至少一对明确的 `Closed/Contest` 和 `Open/Ready` 手部姿态，能在编辑器直接旋转真实人物手指骨骼、保存、重新打开和应用；有可复用的源文件/姿态配置。**不能只改原来七组表面标记，再调用自动接触搜索器就宣布“美术定姿”。**
3. **仍可换人物：** Rocketbox 与本机 Ch03 两个不同 Humanoid 可使用相同的握姿语义和解算/动画路径，区别只在 Profile/小量角色专属姿态校准；不要复制 Rocketbox 原始局部四元数给另一套骨架，也不新增两套独立控制器。
4. **主场景实际运行：** 新握姿接入 `ArmWrestlingMain`，跟随单一 Grip Anchor，保留原准备/对抗 Clip、Blend Tree、IK、较稳定肘支撑、碰撞诊断与已有回退；检查 ±30° 往返动作。仅在真实画面和腕/肘指标均有所改进、无明显新增深穿模时，才更改默认；否则保持原稳定模式并准确汇报。

## 必须采用的工作方式

**先看成熟工具 → 在真实骨骼上做美术定姿 → 视觉检查 → 直接集成 → Editor 回归与公开证据，一次完成。** 这是完整实施任务，不是新一轮“研究后再等授权”。

- 先读 [P2-E 现成方案参考](../research/P2E-authored-hand-pose-workflow.md)、`AGENTS.md`、[P2-D 最终失败与回退](../P2D-joint-constraints-result.md)、[当前稳定画廊](../validation/p2d-joint-constraints/README.md)。
- 优先使用已有 `PairedContactPreview`、`ContactGripAuthoring`，参考 UltimateXR Fixed/Blend Pose，扩充必要的**单指/单关节可视化编辑与姿态快照**。如果 Editor 可视操作不方便，可用 Unity Editor 脚本固定姿态/反复捕获画面进行明确的美术修改，或在本机已有 Blender 的情况下用 Blender Pose Library/骨骼模式制作。**不能再做无上限的全局 muscle/接触阈值随机或网格搜索。**
- 允许采用正规手势素材作为编辑起点，但必须检查可再分发许可、骨骼/版本兼容；参考真实扳手腕握手照片/视频只用于制作，不把未经许可的参考图片上传 Public GitHub。
- 首先在**两只完整的 Rocketbox 右手网格同时可见**的零位编辑，明确哪只手的拇指搭在哪里、四指包握另一只手的哪片掌面。先摆腕、掌根、虎口，再逐指修 MCP/PIP/DIP，核对正反两侧，避免只从一个“好看”视角摆姿态。
- 保存两侧腕相对 Grip Anchor 的位姿 + 两侧 Open/Closed 手指姿态，以及必要的接触参考；检查再次加载不会丢失。美术姿态为主，现有 ContactGrip 只负责少量残余接触，不应覆盖已定好的自然手势。
- 第二骨架 Ch03 必须在本机实际导入/重定向试用；可自行决定自动肌肉重定向 + 少量人工 Avatar Profile override 的具体实现。Ch03 的 FBX、衍生资源和画面**不可公开上传**。

## 本轮从最小有效结果做到完整交付

**先零位、再动态，不拆阶段：**

1. 用真实的 0° 同镜头与现有稳定模式比较：玩家/对手双掌相对、指腹实际位置、拇指搭扣、掌根/指骨互穿、腕部是否反折；检查右/左（观察侧）和反侧。
2. 在同一主场景用 `−30°、0°、+30°` 和约 181 帧、6 秒连续往返试验；不是只给静态握姿编辑器截图。原有机械角度、Grip Anchor 世界轨迹和 Animator 相位保持。对手手臂不得为配合手势而明显穿胸、异常滑肘或严重穿肘垫。
3. 对 Rocketbox、Ch03 及混合人物尽量复用现有完整比赛回归工具，至少验证新模式、当前稳定模式、默认胶囊和缺资源回退实际 Editor Play。所有无实际运行的项目须写“未测”；不要宣称 PICO/PCVR/STM32/UDP 或实物已通过。
4. **主要看可见画面、辅以数字**：在相同测量口径下记录双腕最大折角、手部/掌根重叠代理、肘与垫采样、明显扭转/松指、与共同握点误差。不设置绝对毫米门槛强迫更难看的姿态。若新姿态确实比旧版明显更自然且没有重要回退，可设为默认；如无可行结果，保持稳定默认、保留可编辑资产和失败证据，避免继续调参。
5. **上传用户能直接看到的证据**：GitHub `docs/validation/p2e-authored-grip/` 下零位同机位 Before/After PNG（第一人称、正面、侧面/反侧）、±30° 关键帧、至少一个真实 Unity 编辑器连续 GIF；确保每张尽量 <1 MiB、GIF <8 MiB。GIF 为真实帧抽样，不是补画。包含未授权 Ch03 的画面只留本机。可复用旧的发布脚本，不要改写原 P2-D 画廊。
6. 新增简短 `docs/P2E-authored-grip-result.md`：采用的工具与来源、到底怎样直接编辑并保存姿态、两套骨架适配方式、零位/动态真实对照、性能/限制、实际 Unity 测试状态，以及用户如何手动继续编辑这套姿态。将该文档和 PNG/GIF 链接嵌入 PR #11 描述或评论。

## 自主权、边界和结束条件

- Codex 有权快速研究、选择最省事可用工具、改 Inspector/Editor、创制姿态资产、修复现有功能并回归，不需每个小步骤询问用户。**验证有效后直接集成、推送，不因“验证成功”再次停下申请批准。**
- 优先最少可读代码和 Unity 现有能力；不为美术姿态重写 P0～P2-D、不安装整个 Meta/UltimateXR SDK、不制造新的庞大手部物理框架、不做无休止参数搜索。
- 不改动 PC `armwrestling` 仓库、既有 UDP V0.1、STM32、磁粉制动器、真实机械尺寸或方向。不因为演示效果而改变机械轨迹。
- 主场景保留通用模型适配及 `LegacyHumanoidGrip` 回退；**先保留稳定默认，直到有真实画面支持切换**。
- 本轮必须尝试得到**实际保存的可编辑、可加载的美术握姿**并在主场景运行，不以仅增加骨骼编辑器 UI 或文档代替结果。若经有界真实尝试仍不够自然，诚实交付最优已保存姿态 + 证据与具体卡点，停止这一轮，不扩大搜索。
- **继续并推送当前分支 `feat/p2d-cross-avatar-grip`、更新 Draft PR #11，暂不合并。** 不增加新的层叠分支。

**原则：美术自然姿态在前，骨骼重定向和残余接触在后；既要换模型可用，也要真正像两个人在扳手腕。**
