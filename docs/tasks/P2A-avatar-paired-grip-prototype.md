# P2-A｜正常人体素材验证与成对扳手腕握姿原型

> **已完成 Editor 原型。** [结果、复现和限制](../P2A-avatar-and-paired-grip-result.md)。 从 `main` 的 P1-E 稳定基线（调研原则提交 `8956e4f`）开始，具体工作分支 `feat/p2a-avatar-paired-grip`。目标是改进**真实画面**：两个人像正常人，并以正确的扳手腕方式握在一起。上阶段零散手指调参已到收益瓶颈；这次先验证现成资产及成熟姿态工作流。

先阅读 [调研与候选方案](../research/P2A-avatar-and-grip-references.md)、`AGENTS.md`、`README.md`、`docs/P1E-hand-contact-result.md`，再在本机 Windows/Unity 2022.3.62f3c1 中实施。不必每个决定向用户请求确认，优先做真实能看见的结果。

## 本轮决策原则

- **先查成熟做法再动手**。已有候选：MIT 的 [Microsoft Rocketbox](https://github.com/microsoft/Microsoft-Rocketbox)、CC0 核心素材的 [MakeHuman](https://www.makehumancommunity.org/)、[Meta HandGrabPose 概念](https://developers.meta.com/vr/documentation/unity/unity-isdk-hand-grab-interaction/)、[Blender Pose Library](https://docs.blender.org/manual/zh-hans/4.5/animation/armatures/posing/editing/pose_library.html)。这些是**候选，不是必须照搬**。结合实际版本、肤色服装视觉、骨骼和授权选择一条最短的可行路线，必要时报告为什么放弃。
- 不再只以“掌面法线更接近 180°”“疑似穿入点下降”判断完成。**静态近景里像两个正常人正在扳手腕，是这轮首要验收门槛**。
- 必须明确人与设备之间的动作输入：只由现有 `Grip Anchor`（单自由度）驱动双方握持的空间运动，预先摆好的左右各自手腕与指骨姿态定义握持关系，既有 Animator/IK 负责两条手臂和身体随动。

## 第一部分：人物资源快速试用

1. 首选从 Rocketbox **仅选 1 名**外观自然、服装/脸/手清楚的人物作为对手，尽可能沿用有许可证的贴图材质；资源可预先粗看 **`Assets/Avatars/Adults/`** 中的成年人。不下载整个数 GB 仓库。可根据便利选第二位或同一人物的两套外观作玩家第一人称手臂；玩家只需模型中右手与部分右臂。
2. 用可重复的方法导入本机 Unity；**别直接复制官方 `FixRocketboxMaxImport.cs` 全局后处理脚本**，其源代码默认将导入模型设为 Generic，可能破坏本工程原 Humanoid。只对新模型所需路径适配材质、Avatar、骨架。
3. **硬验证**：模型面部、材质/贴图在 Unity 里正确显示；`Animator.isHuman` 和 Avatar 有效；骨骼能控制头、肩、肘、腕，尤其右手拇指、食指、中指、无名指、小指 15 个指骨可映射并带蒙皮动作。若没有完备手指骨或网格错误，尽快换候选/用 MakeHuman，不要让错误资源绑架动作方案。
4. 先完成**中立坐姿的人物外观**和第一人称玩家正常手臂。保留 P1-E 本机 Ch03 模式与公开胶囊回退。候选资源 MIT/CC0 可在核准全部实际用到的 FBX、贴图/服装的来源和条款后，只提交少量**必要且体积优化**的实际依赖并带原许可归属。版权来源不确定、太大的实验文件及录屏先保留本地，明确说明为什么未公开。不得无目的引入 115 个模型或 417 段动作。

## 第二部分：人工设计“一套成对的手部握姿”（核心）

1. 使用真实右手扳手腕对握参考，**先固定视觉零位**。与当前截图的“抓手腕、钩爪手指”比较，将两人**掌面对掌、拇指合理相搭、四指自然包握、腕与前臂方向协调**地摆好。可使用 Blender 姿态资产/Unity 编辑器骨骼调姿工具/现成可编辑握姿；不要靠全局随机搜索 15 指骨角度。若方便，保存中立时的可复用姿态预设和来源或参考图（版权不明图片不公开）。
2. 为每个人存储**相对共同 Grip Anchor 的手腕位置+朝向，及各自的手指骨骼局部旋转**。两个掌心不必重合，但不允许把手大幅拉开或抓住前臂来逃避穿模。若涉及手势骨骼重定向，保持实现清晰并说明针对不同身材的缩放/微调入口。
3. 接到现有 `SeatedPrepare` / `SeatedContest`、Effort Blend Tree 和原有/必要改进的 IK；必须保留 P1-D/E 对手相对稳定的肘部。静态姿态正确后再让两只手作为共同握姿整体跟随单自由度，从 `0°` 扩展到 `−30°/0°/+30°` 和 181 帧往返，发现端点不可达时清楚记录，不许拉伸人体骨骼。
4. 用实际蒙皮手指/掌面接触视觉对比，适当复用 `HandContactProbe`，但不要把稀疏顶点法线判据称作完美碰撞检测。不要求每毫米都完全无穿模，本阶段优先纠正**握错位置和人物不像人**这两个结构性问题。

- **必须实际跑 Unity Editor Play**：中立双手的近景（正、侧、第一人称）、一次 ±30° 往返短视频、正常人物正/侧/第一人称画面。尽量和上一轮同机位画面放一起对照；不能只提交新代码或指标。手指/皮肤可见，不能仍是模型全白或手掌钩爪。
