# P1-C｜实物几何标定准备与手部接触预研

> 状态：**待 Codex 执行**。基于已完成 P1-B 的 `a2afe3c`；[P1-B 结果](../P1B-elbow-contact-result.md)。本任务优先确认哪些几何量需要实测、哪些已有可靠来源，再考虑继续优化动画。**没有实际测量数据时，不得假称已完成实物对齐。**

## 已有成果与必须保留的边界

- P1-B 在 Unity 中国版 2022.3.62f3c1 的真实 Editor Play 中完成 181 帧、±30° 视觉角往返：Ch03 肘部蒙皮局部采样下缘平均距**演示**肘垫由 65.2 mm 降为 2.4 mm，投影 181/181 帧在演示垫内；最大掌心**代理点**误差约 3.31 mm。±42° 负端有约 0.7 mm 的蒙皮采样穿入。
- P1-B 调整的是 **Ch03 的演示垫**：中心 x −210→−155 mm、上表面 y 42.5→95 mm、宽度 240→300 mm；真实装置仍未测量。保留这一套 **Demo 基线**，不要把这些尺寸默认为实体结构。
- 动作路线暂定 **三档躯干姿态插值 + Animator 手脚 IK**；本轮不再评选新框架。P0 离线比赛流程/默认胶囊场景必须保持可运行。
- `armwrestling`（PC 控制）是独立仓库，不修改其代码与既有 UDP V0.1。该仓库 `docs/trajectory-fit.md`、机械候选 C、MuJoCo 坐标/尺寸可以用作背景及计算参考，但属于**仿真设计/示意**，不等于实物测量。
- VR 内当前示意单轴绕设备 +Z 旋转；原 PC/MuJoCo 仿真采用不同的世界轴约定。真实测量要明确坐标变换、正负方向及零位，不能直接复制坐标数字。控制侧“获胜方向下压”约定为**负机械角 rad**；VR 的视觉角正负需要明确可配置映射。

## 第一部分：为实物测量建立最小、能使用的交接

1. 检查原工程、P1-B 的姿态/几何代码和原 PC 仓库已有 CAD/文档/图片。快速梳理当前 Unity Demo 常量与可确认的机械设计量，区分：
   - **实际量测**（要有来源、时间、基准）；
   - **已冻结 CAD/设计值**（还需核实是否与实物一致）；
   - **Unity/MuJoCo 演示值**；
   - **缺失数据**。
2. 生成简短易操作的 `docs/calibration/physical-measurement-guide.md`，让用户/机械同学能对照真实装置测量，不要写冗长学术论文。至少覆盖：
   - 统一参考坐标系和桌面基准（长度 mm、角度 deg/rad；用户所在侧与左右手）；
   - 输出转轴中心点及**轴线方向**（最好两点/方向向量，而非只给一个位置）；
   - 真实握把的**握持中心**与握把轴线/朝向，0 位及两侧至少两个典型机械角度下的握持位置/变化；若已有 CAD 可提供轨迹但须标注来源；
   - 真实肘垫上表面中心、宽深高、方向、可滑动区域；座椅/坐姿参考点与头显视点若可测；
   - 实际零位、获胜方向的符号、机械允许行程、被动握把是否能自行转动，以及相机与真实手柄的空间对齐需要哪些标记；
   - 记录来源/不确定性/是否真实量测，未知就标“待测”，**不得用 0 或演示默认值冒充测量**。
3. 提供少量方便填写的表格、CSV/JSON 模板或一张带标记示意图（选最方便用户使用的），并说明如何把获得的测量值交给下轮 Codex。不要要求接上有励磁的制动器、进行真人对抗或增加硬件风险；静态标定即可。
4. 必要时增加简短的校准/可达计算辅助工具；优先复用已有 `AnimationComparison.cs` 导出的 CSV 和现有几何分析，不为缺失数据构建大型通用标定平台。能使用的实测数据若现阶段确实不存在，本阶段可先交付测量清单和复用方案。

## 第二部分：不依赖实物尺寸的局部手部动作探索（可自主选择）

- 优先检查本地 Ch03 Humanoid 的手指/拇指骨骼是否真的存在且可编辑；观察它与**现有球形玩家手**的穿插，这是目前较明显的视觉问题。
- 如骨骼允许，可试一个**最小静态握手/弯指姿态**或随角度保持的简单闭合姿态，使对手手指看起来包住对方的手而不是张开。用已有 Animator/少量关节约束即可，不必引入完整抓握动画库或物理碰撞手。
- 保持实时掌心跟随和右腕 IK；避免新手指旋转打断 IK 或让腕/肘、身体失稳。建议沿用 −30°、0°、+30° 和一次往返测试。
- 若 Ch03 手指骨骼不足、姿态很难复用，明确记录障碍和最低成本替代方案即可，不强制换模型。未做真实掌面/网格接触或压力测试，不能声称“真实无穿模”。
- **手指与负端腕部可以先做小幅视觉改进，严格几何校准要等真实装置尺寸。** 不要因为缺实物数据就无限微调 Demo 肘垫。
