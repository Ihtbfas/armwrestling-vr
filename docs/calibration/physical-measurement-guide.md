# 扳手腕实物几何测量指南

先交回三类数据即可开始拟合。**输出转轴的两个中心点、零位与两侧的握持中心和朝向、实际肘垫顶面与椅面基准。** 本轮只准备测量，尚未实物标定。

## 现场怎么量

1. **准备静态位置。** 在实验室负责人确认装置断电、无励磁、摆臂可在安全位置静态固定后测量。准备卷尺或卡尺、直角尺、水平尺、量角工具与胶带。需要转到下一角度时按现场静态固定流程操作。测不到的位置写“待测”并注明原因。
2. **定一个桌面坐标系。** 从操作者坐的一侧看，(O) 取靠人桌边中点在桌面上表面的位置，用胶带标出来。右手系 **X 向操作者右侧，Y 远离操作者，Z 向上**，坐标都相对同一个 (O)，用 **mm**。桌边中心不明确时可选一处固定角点，拍照注明位置和三轴箭头。用直角尺把每个点投影到桌面读 X/Y，沿桌面法向读 Z，同时记录使用左手还是右手和桌面离地高度。
3. **确定输出轴线和零位。** 在实际带动摆臂的输出轴上，选相隔尽量远的两处中心 (A,B)。例如轴端圆心与另一轴承内圆中心。在照片上标明 (A→B) 的方向，以免把制动器轴或中间轴当成输出轴。若只有一个端面可见，记录该中心和可追溯的轴向测量或 CAD 基准。标出装配上的机械零位、参考刻线和回零方式。可安全读取时同时抄录编码器原读数与单位。
4. **固定角度，记录握把。** 至少记录零位、获胜侧、另一侧各一组，能做时每侧再加一组靠近允许行程端点的姿态。每组记录同一握持标记 (G) 的 XYZ、握把中心线上两个可重找的点 (H1,H2)，以及正反向实际角度与单位。有偏心、偏置套筒或手握位置偏离套筒中点时，单独标明 (G) 的定义。记录有效握持长度、直径和握把是否能绕自身旋转。可自转时在套筒上加一个不在轴线上的标记 (R)，注明每组的滚转状态。
5. **测接触面和座位。** 标记实际使用侧肘垫的顶面中心 (P) 与可滑动区域边界，测宽、深、相对桌面抬高。按同方向记录三个不同角点；若面倾斜，直接记录各点 XYZ 并标明垫面方向。座椅放在实际使用位置，记录椅面前沿中点或可重复定位的坐骨参考点 (S)、椅面高度与朝向。后续可另记舒适坐姿下的肘部落点、腕骨到实际握持标记的偏置和头显视点。
6. **确认方向和登记照片。** 在说明中标出哪一侧是“下压获胜”。另画从零位到该侧的箭头。记录机械止挡与实验允许行程各自的两端，区别绝对角、相对零位角和编码器读数。工程约定下压获胜为负机械角，现场读数如果相反就记录原始符号，后续映射。拍俯视和侧视带比例尺的照片，给 O、A、B、G、肘垫与椅面标号。计划做 VR 对齐时，在桌面固定至少三个非共线标记，记录它们的桌面 XYZ 和头显或相机坐标下的 XYZ，注明追踪空间原点、轴向与采集时刻。

每个关键点优先重复测两次，记录读数差和大致不确定性。角度请写 **deg** 或 **rad**，编码器原始计数另列。照片用于识别点位与姿态。只有清楚的比例与基准才能拿照片读尺寸。

拿到数据后，以 A→B 为轴、G 的零位点为起点，先用多个测点核对离轴半径、圆弧平面残差和角度符号，再由 H1/H2 与 R 确定握把方向及可测滚转。用另行实测的腕骨到握点偏置推算腕轨迹，并结合实际可滑肘区域计算可达性。记录的点已相对桌边标记 O。现有 Unity 装置原点在桌面中心 C，接入时先用两点同一坐标系求相对位移 q=P−C，再按 (qX,qZ,qY)/1000 换到 Unity 局部米坐标。用两侧实测姿态检验旋转方向。这个换轴有手性变化，角度符号不可直接照抄。现有 UDP 保持机械 rad，VR 中的视觉角映射另行标定。
